# Automation & Enterprise Network Lab

A comprehensive, scalable Cisco Packet Tracer topology designed to demonstrate core routing, switching, wireless management, and infrastructure security protocols.

## 🚀 Key Features Implemented

### 1. Routing & Core Infrastructure
* **Dynamic Routing:** Configured **OSPFv2 (Area 0)** across all core ISR routers for automatic path calculation and network redundancy.
* **Gateway Management:** High-performance routing handling traffic between internal LANs and simulated public WAN links.

### 2. Switching & Local Area Networks (LAN)
* **VLAN Segmentation:** Broadcast domains segmented to isolate internal staff, local servers, and guest infrastructure.
* **Inter-VLAN Routing:** Configured to allow secure communication across separate virtual networks.

### 3. Wireless & Server Management
* **Wireless LAN Controllers (WLC):** Enterprise wireless infrastructure managing active connections for mobile and laptop endpoints.
* **Local Services:** Configured internal servers to handle active network traffic, data transfers, and standard protocol requests.
